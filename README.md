# Cotizador 3D | Aluminio Plascencia

Sitio web estático premium con un cotizador visual interactivo en 3D para sistemas de aluminio y cristal.

## 🚀 Características
- **Visualización 3D en tiempo real**: Renderizado con Three.js.
- **Diseño Responsive**: Optimizado para móviles, tablets y escritorio.
- **Interfaz Premium**: Estilos Glassmorphism, animaciones suaves con GSAP y Tailwind CSS.
- **Soporte Multitouch**: Gestos nativos de zoom y rotación en dispositivos móviles.

## 🛠️ Tecnologías
- HTML5, CSS3, JavaScript (ES6+)
- Three.js (Renderizado 3D)
- GSAP + ScrollTrigger (Animaciones)
- Tailwind CSS (vía CDN para estilos utilitarios)

## 🌐 Cómo ejecutarlo localmente
Debido a las políticas de seguridad de los módulos ES6 y Three.js, necesitas un servidor local.
1. Instala la extensión **Live Server** en VS Code.
2. Haz clic derecho en `index.html` y selecciona "Open with Live Server".
3. O usa Python: `python -m http.server 8000`
